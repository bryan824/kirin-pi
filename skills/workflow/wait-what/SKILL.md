# Wait, what?

Repair understanding, not just message length. Back up to the missing premise and
re-explain the confusing point in clear, natural language. Define necessary terms;
use established project names and a concrete example or small inline diagram when
it helps. Consult a relevant existing glossary if useful; do not require or create one.

Keep the important conditions, uncertainty and consequences. If the confusing point
is unclear, ask one focused question; otherwise explain directly. Stay in the current
conversation—no files, learning workspace or teaching mode unless requested.
