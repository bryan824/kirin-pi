# Decision Frontier

Use when dependent uncertainty outlives the current conversation. Keep one set of
working notes for the task, not a workflow engine or a record per question.

Capture the destination, standing constraints, exclusions, settled decisions and
their evidence. Index open questions by readable titles; add stable IDs and
blocker links only where cross-references need them. Questions not yet clear
enough to phrase remain explicit unknowns, not invented downstream work.

A question is ready when its prerequisites are settled. Route facts to evidence,
human choices to the decision-maker, and runnable uncertainty to an authorized
experiment. Access/provisioning work is not implicitly approved because it would
unblock a decision.

After a resolution, record the decision, consequences, evidence and any revisit
condition. Reconsider dependent questions and scope. Do not copy a research report
into several records or create a second task/claim store beside the active runtime.

An implementation slice can proceed when its own consequential prerequisites are
resolved and it is authorized; unrelated open branches need not block it. An
unresolved requirement remains a blocker or explicit user-approved deferral, not
an implied agreement. Preserve existing records; migration or cleanup needs its
own authority.
